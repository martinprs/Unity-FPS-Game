# Unity-FPS-Game
Simple first person shooter game for a school assignment. The objective of the game is to survive 5 minutes without dying. The world is filled with evil beans who are constantly hunting you. Killing the beans will make them spawn useful items such as healtpacks & ammo that keep you alive. This game is not finished, I managed to rush it to a "playable" state, there are a lot of problems that need fixing.

## How to build the game yourself?
Since its a Unity game you need to [install](https://cloud.unity.com/home/organizations/5773926382149/onboarding/post-download) Unity to your computer <br>
<br>
Clone the repository
```
git clone https://github.com/martinprs/Unity-FPS-Game.git
```
Open the project in Unity and go to **File** -> **Build settings** (select all scenes) -> **Build**
